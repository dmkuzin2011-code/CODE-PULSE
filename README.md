# CODE-PULSE
 Code-pulse is a program that is inspired by CLI tools and programs such as *Git*.
 At the moment, there is only a beta version in Python, it implements only basic things
 and does not have integration with databases such as PostgreSQL,
 so it cannot be said that the basis is ready at the moment.
